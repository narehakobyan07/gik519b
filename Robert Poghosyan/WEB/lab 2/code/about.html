Հայաստան Տուր գործակալություն

Հայաստան Տուրը զբաղվում է Հայաստանի տարբեր մարզերում զբոսաշրջային երթուղիների կազմակերպմամբ։

Մենք առաջարկում ենք պատմամշակութային, բնապահպանական և ճանաչողական ճանապարհորդություններ։

Մեր առաքելությունը

Մեր նպատակն է ճանապարհորդներին հնարավորություն տալ բացահայտելու Հայաստանի պատմությունը, մշակույթը և բնությունը։

Մեր ծառայությունները

Կազմակերպում ենք ուղևորություններ, ուղեկցորդի ծառայություններ և տուրերի նախնական ամրագրում։

Հաճախորդների համար

Յուրաքանչյուր ճանապարհորդ կարող է ընտրել իրեն համապատասխան երթուղին և ժամանակացույցը։

Կարևոր նշում

Ճանապարհորդությունից առաջ անհրաժեշտ է ստուգել տուրի վերջնական ժամը, արժեքը և հասանելի տեղերը։

Օգտագործման ուղեցույց

HTML-ը վեբ էջերի կառուցվածքը ստեղծելու ստանդարտ նշագրման լեզու է։

Թեգ-ը HTML փաստաթղթում օգտագործվող կառուցվածքային նշում է։

Վեբ ստանդարտները օգնում են ստեղծել կառուցվածքային և հասանելի վեբ էջեր։

Օրինակ՝ օգտվողին կարելի է ասել՝ Ստուգեք ձեր ամրագրումը նախքան ճանապարհորդությունը։

Տեղեկատվական աղբյուր՝ World Wide Web Consortium (W3C)։

HTML կոդի օրինակ

<p>Բարի գալուստ Հայաստան Տուր։</p>
<a href="about.html">Մեր մասին</a>

Ֆայլը պահպանելու համար կարելի է օգտագործել Ctrl + S։

Օրինակային համակարգային հաղորդագրություն՝ File saved successfully.

Եթե n-ը ճանապարհորդների քանակն է, ապա ընդհանուր արժեքը կախված է n-ից։

HTML, XML և XHTML

HTML-ը վեբ էջերի կառուցվածքը ստեղծելու համար օգտագործվող նշագրման լեզու է։

XML-ը տվյալների կառուցվածքային ներկայացման և պահպանման համար նախատեսված ընդարձակվող նշագրման լեզու է։

XHTML-ը HTML-ի ձև է, որը հետևում է XML-ի ավելի խիստ շարահյուսական կանոններին։

HTML-ում նկարը կարող է գրվել այսպես՝ <img src="images/garni.png" alt="Գառնի">։

XHTML-ում նույն տարրը գրվում է փակվող սլեշով՝ <img src="images/garni.png" alt="Գառնի" />։

XHTML-ում տարրերը պետք է ճիշտ փակվեն, ատրիբուտները պետք է ճիշտ ձևակերպվեն, իսկ XML-ի շարահյուսական կանոնները պետք է պահպանվեն։
