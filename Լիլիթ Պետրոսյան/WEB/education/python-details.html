Python Ծրագրավորում (Core Python, Django, REST API)

Սովորեք աշխարհում ամենապահանջված ծրագրավորման լեզուներից մեկը 0-ից։ Դասընթացը ներառում է ալգորիթմներ, ՕՕԾ (OOP), Django framework, տվյալների բազաներ և API-ների ստեղծում։

⏱️ Տևողությունը: 5 ամիս 📊 Մակարդակ: Սկսնակից Junior/Middle 📜 Վկայական: Տրվում է

Ինչ եք սովորելու

  • Python-ի հիմնական սինտաքս, տվյալների տիպեր և կառուցվածքներ (Lists, Dicts, Tuples, Sets)
  • Օբյեկտին կողմնորոշված ծրագրավորում (OOP) և Clean Code-ի պրինցիպներ
  • Աշխատանք ֆայլերի (File I/O) և JSON տվյալների հետ
  • Տվյալների բազաներ՝ PostgreSQL, SQLite և ORM (SQLAlchemy, Django ORM)
  • Web Development Django / FastAPI framework-ներով
  • RESTful API-ների ստեղծում (Django REST Framework) և Git/GitHub
