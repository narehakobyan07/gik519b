Վեբ Ծրագրավորում (Frontend / Backend)

Սովորեք ստեղծել ժամանակակից, ադապտիվ և դինամիկ վեբ կայքեր 0-ից։ Դասընթացը ներառում է HTML, CSS, JavaScript, React.js և Backend-ի հիմունքներ։

⏱️ Տևողությունը: 6 ամիս 📊 Մակարդակ: Սկսնակից Junior/Middle 📜 Վկայական: Տրվում է

Ինչ եք սովորելու

  • HTML5 և CSS3՝ կայքերի կառուցվածք և ձևավորում
  • Flexbox, CSS Grid և ադապտիվ (Responsive) դիզայն
  • JavaScript (ES6+)՝ դինամիկ ինտերակտիվություն
  • React.js՝ modern Single Page Applications (SPA) ստեղծում
  • Git/GitHub՝ կոդի կառավարում և թիմային աշխատանք
  • REST API-ների հետ աշխատանք և Backend-ի հիմունքներ

Դասընթացի Ծրագիրը

Փուլ 1: Frontend Հիմունքներ (HTML5, CSS3, JavaScript)
Փուլ 2: Խորացված JS & Frameworks (React.js, Redux)
Փուլ 3: Node.js, Express & Database (MongoDB/SQL)
Փուլ 4: Ավարտական Պորտֆոլիո Նախագիծ (Real Project)
