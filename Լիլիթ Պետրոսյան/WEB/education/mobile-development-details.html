Մոբայլ Հավելվածների Մշակում (Flutter / React Native / iOS & Android)

Սովորեք ստեղծել ժամանակակից, արագագործ և սպլատֆորմ (iOS & Android) բջջային հավելվածներ 0-ից՝ օգտագործելով Flutter/Dart կամ React Native տեխնոլոգիաները։

⏱️ Տևողությունը: 5 ամիս 📊 Մակարդակ: Սկսնակից Junior/Middle 📜 Վկայական: Տրվում է

Ինչ եք սովորելու

  • Dart/JavaScript/TypeScript լեզուների հիմունքներ և ՕՕԾ (OOP) պրինցիպներ
  • Flutter/React Native UI Widgets, layout-ների կառուցում և ադապտիվ դիզայն
  • State Management (Bloc, Provider, Redux, Zustand) բարդ տվյալների հոսքի համար
  • Աշխատանք REST API, GraphQL և Firebase-ի հետ (Authentication, Cloud Firestore, Push Notifications)
  • Լոկալ տվյալների բազաներ (SQLite, Hive, Async Storage)
  • Հավելվածների հրապարակում App Store-ում (iOS) և Google Play Store-ում (Android)
