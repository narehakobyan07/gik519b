10. HTML, XML և XHTML Տարբերությունները

HTML-ը նախատեսված է վեբ էջերի կառուցվածքը ստեղծելու և տվյալները ցուցադրելու համար: XML-ը կենտրոնանում է տվյալները պահպանելու և փոխանցելու վրա, որտեղ թեգերը սահմանվում են օգտագործողի կողմից: XHTML-ը հանդիսանում է HTML-ի ավելի խիստ տարբերակը, որը բազավորված է XML-ի կանոնների վրա և պահանջում է անպայման փակել բոլոր թեգերը:

Օրինակ՝ սովորական պատկերի տեղադրման տարբերությունը HTML-ում և XHTML-ում ունի հետևյալ տեսքը.

  • HTML գրառում (չփակվող)՝ <img src="image.jpg" alt="Նկար">
  • XHTML գրառում (ինքնափակվող)՝ <img src="image.jpg" alt="Նկար" />

Օգտագործման Ուղեցույց և Տերմիններ

Ժանր
Ֆիլմերի տեսակավորման ձևն է ըստ բովանդակության (օրինակ՝ դրամա, կոմեդիա):
Սցենար
Գրավոր տեքստ, որի հիման վրա նկարահանվում է ֆիլմը:
Ենթագիր
Ֆիլմի տակից երևացող տեքստային թարգմանությունը (սուբտիտր):
Կինոն արվեստ է, որը թույլ է տալիս տեսնել անտեսանելին: - Հայտնի Կինոքննադատ

Ծրագրում HTML տարր սահմանելիս թեգը և հատկանիշը առանձնանում են հետևյալ կերպ. <tag attribute="value">, որտեղ tag-ը թեգի անունն է, իսկ attribute-ը՝ հատկանիշը:

Ծրագրային Կոդի Օրինակ (Guide)

    // Կոդի պարզ ցուցադրում
    #include <iostream>
    int main() {
        std::cout << "Hello Cinema!";
        return 0;
    }

Խմբագրիչում կոդը պահպանելու համար սեղմեք Ctrl + S ստեղները, որից հետո էկրանին կհայտնվի File saved successfully հաղորդագրությունը:
