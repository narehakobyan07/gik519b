Ընդունվելու կարգը

Դպրոց ընդունվելու համար կատարեք հետևյալ քայլերը.

  1. Լրացրեք գրանցման հայտը դպրոցի էլ. փոստով։
  2. Մասնակցեք անվճար փորձնական դասին։
  3. Ընտրեք բաժինը, դասավանդողին և դասի ժամը։
  4. Վճարեք առաջին ամսվա վարձը և ստացեք դասացուցակը։

Դասացուցակ և վճարներ

Երաժշտական դասերի ժամանակացույցը և ամսավճարները (տվյալները հորինված են)

Վոկալ Երգեցողություն Լուսինե Ավետիսյան 17:30 17000

Վերնագրերի ուսումնական օրինակ

Այս բաժինը ցույց է տալիս, թե ինչպես վերնագրերը իջնում են հաջորդաբար՝ h1-ից մինչև h6, առանց մակարդակներ բաց թողնելու։

Ստեղնավոր գործիքների բաժին

Երրորդ մակարդակը նշում է ամբողջ բաժինը։

Դաշնամուրի դաս

Չորրորդ մակարդակը բաժնի կոնկրետ դասն է։

Առաջին ամսվա թեմա

Հինգերորդ մակարդակը դասի մի հատվածն է՝ ուսումնական թեման։

Առաջադրանք՝ նվագել «դո» մաժոր գամման

Վեցերորդ մակարդակը վերնագրերի ամենափոքր աստիճանն է՝ թեմայի առանձին առաջադրանքը։

Օգտագործման ուղեցույց

Կայքը բացվում է index.html ֆայլը զննիչում բացելով։ Սակայն ենթագրերի .vtt ֆայլը որոշ զննիչներում չի բեռնվում ֆայլային հասցեից, ուստի ավելի հուսալի է կայքը գործարկել տեղային սերվերով։ Կայքի պանակում կատարեք հետևյալ հրամանը, որտեղ port-ը ձեր ընտրած պորտի համարն է։ 

python -m http.server port

Օրինակ՝ 8000 պորտի դեպքում տերմինալում կերևա այսպիսի արդյունք.

Serving HTTP on :: port 8000 (http://[::]:8000/) ...

Դրանից հետո զննիչում բացեք http://localhost:8000 հասցեն։ Սերվերը կանգնեցնելու համար տերմինալում սեղմեք Ctrl + C։

Տեսանյութի հայերեն ենթագրերը միացվում են այս տողով (նշաններ՝ < և >).

<track kind="subtitles" src="media/lesson-subtitles.vtt"
       srclang="hy" label="Հայերեն" default>

HTML, XML և XHTML

HTML-ը վեբ էջերի նշագրման լեզու է, որը զննիչներն ընդունում են նույնիսկ փոքր սխալների դեպքում։ XML-ը տվյալներ նկարագրելու ընդհանուր նշագրման լեզու է, որտեղ թեգերը կարելի է ինքնուրույն ստեղծել, բայց շարահյուսական կանոնները խիստ են։ XHTML-ը HTML-ի այն տարբերակն է, որը գրվում է XML-ի կանոններով, ուստի բոլոր թեգերը պետք է փակվեն, անունները՝ գրվեն փոքր տառերով, իսկ հատկանիշների արժեքները՝ չակերտների մեջ։ Այդ պատճառով դատարկ տարրերը, օրինակ՝ պատկերը, XHTML-ում փակվում են հենց թեգի ներսում՝ <img />։

HTML տարրի օրինակ՝ հղում դեպի գլխավոր էջը.

<a href="index.html">Գլխավոր</a>
  • Թեգ (տարրի անունը)՝ a. բացող թեգը <a> է, փակողը՝ </a>։
  • Հատկանիշ՝ href, որի արժեքը "index.html" է։
  • Տարրի բովանդակություն՝ «Գլխավոր» տեքստը։

Նույն պատկերը երկու գրառմամբ.

HTML:  <img src="images/lesson1.jpg" alt="Դաշնամուրի դաս">
XHTML: <img src="images/lesson1.jpg" alt="Դաշնամուրի դաս" />

XHTML-ի գրառումը ենթարկվում է XML-ի շարահյուսական կանոններին, ուստի դատարկ img տարրը պարտադիր փակվում է /> նշանով, մինչդեռ HTML-ում այդ փակումը պարտադիր չէ։
